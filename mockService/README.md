# Mock Feishu Server

## Overview
This mock server simulates the behavior of the Feishu API, specifically the `im.message.receive_v1` event and other related interfaces.

## Usage
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the mock server:
   ```bash
   node mock-server.js
   ```
3. The server will start on port 8179.
